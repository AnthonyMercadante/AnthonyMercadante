## OpenMemory

[OpenMemory](https://github.com/Raethexn-Technologies/OpenMemory) explores portable AI memory that is **owned and authorized by the user rather than locked inside an application**.

It combines signed memory writes, portable identity, evolving knowledge graphs, and adaptive retrieval inspired by Physarum conductance dynamics.
