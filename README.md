## OpenMemory

### Your history with AI, in one place you control.

[**OpenMemory**](https://github.com/Raethexn-Technologies/OpenMemory) is an open-source project exploring what AI memory could look like if the **user — rather than the provider — were the persistent boundary around it**.

Most people now interact with several AI systems.

A career discussion might live in ChatGPT.
Programming work might live in Claude.
Research might live in Gemini.

Each system sees only part of the same person.

OpenMemory brings those histories together into a **provider-neutral, user-controlled memory layer**.

It combines:

* historical conversation archives from multiple AI providers
* live memory shared between AI tools through MCP
* provenance-aware retrieval
* evidence-backed answers over conversation history
* timelines and longitudinal analysis
* typed memory and knowledge graphs
* privacy and redaction boundaries
* adaptive retrieval experiments

The larger question is not simply how to search old conversations.

It's what becomes possible when years of interactions with AI can be treated as **one continuous, inspectable history**.
